New wallet

An EVM wallet (Arc, Hyperliquid and any other EVM chain) created and encrypted inside this tab. What you take away is an encrypted file; the address appears once you've checked your backup. This page can't make network requests of its own and loads nothing from outside.

0 · Before you start

For a wallet that will hold real money:

  • Open the copy on your own computer, not the website: the file wallet.html in the launcher's folder (arc-launcher). Its fingerprint is written in BASEY.md.
  • In a Chrome Guest window (profile icon → Guest). Extensions can read any page; a Guest window has none, and no saved passwords.
  • Switch Wi-Fi off once the page has loaded. It doesn't need the network.

1 · Add your own randomness

Move the mouse (or your finger) around the page and type anything until the bar fills. Your device's generator already gives the full 256 random bits a key can hold; this is mixed in on top of it, so it can only add, never take away.

2 · The password

It encrypts the file, and the file plus the password is the wallet. Nobody can recover it: lose either and the wallet is gone for good. Best: let the page make one and write it on paper.

Write it on paper now, exactly as shown, with the dashes. You'll type it again in step 4.
Or type your own

At least 16 characters, and only plain letters, numbers and symbols: no accents, no ñ, no º or ª. MetaMask can't open a file whose password has them, even though this page could.

If the browser offers to suggest or save a password, say no.

3 · Create and download

Keep two copies in two different places (for example this computer and a USB stick), and the paper apart from both. The address appears in step 4, once the saved file has opened: don't send anything to the wallet before that.

4 · Check your backup

Open the file you saved, not this tab's memory, and type the password from your paper (pasting and autofill are refused here). This step also works on its own, any time, to check an old file.

5 · Next

  • Close this tab (better, the whole Guest window) now.
  • Use the wallet from a browser profile of its own. In MetaMask: Add account → Import account → JSON file, with this file and the password. From then on MetaMask can show this key with its password, so that password now protects everything: make it long, and keep nothing else in that profile.
  • Fund it from your exchange account, not from your other wallets, so nothing links them on-chain.
  • When the hardware wallets and the 2-of-3 Safe are ready, the tokens and the fund move there. This wallet can stay as the fee wallet, holding little.
